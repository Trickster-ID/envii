# `envii get` Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox (`- [ ]`) syntax. Follow TDD: write the failing test first, run it, then implement. Do not commit unless the human says so.

**Goal:** Add `envii get <project> <env> <KEY>` that prints one variable's raw value to stdout, so it works in shell substitutions like `export DB_URL=$(envii get my-api dev DB_URL)`.

**Architecture:** One new cobra command in `internal/cli` reusing `loadVault()` and `resolveEnv()`. One new pure lookup method on `*model.Env` (`FindVar`). Output rules: value + newline on **stdout only**; all errors on **stderr** with non-zero exit. Secret values are printed raw (this is a machine interface; masking would break `$(...)` usage).

**Tech Stack:** Go, cobra, stdlib `testing`. No new dependencies.

## Global Constraints

- Packages touched: `internal/model`, `internal/cli` only
- No new dependencies
- No TUI changes
- Value goes to `defaultIO.Stdout()`, everything else to `defaultIO.Stderr()`
- Exact case-sensitive key match
- Tests must be table-driven and follow the existing style in `internal/cli/cli_more_test.go` (use `fakeIO`, `withIO`, `withVaultPath`, `seedVault`, `sampleVault`, `withExit`)

### Task 1: `Env.FindVar` in model

**Files:** `internal/model/model.go`, `internal/model/model_test.go`

Add to `internal/model/model.go`, next to `FindEnv` / `Map`:

```go
// FindVar returns the var with the given key, or nil.
func (e *Env) FindVar(key string) *Var {
	for _, v := range e.Vars {
		if v.Key == key {
			return v
		}
	}
	return nil
}
```

### Task 2: `getCmd` + registration

**Files:** `internal/cli/commands.go`, `internal/cli/cli.go`, test file

Behavior spec:

| Input | Result |
|---|---|
| `envii get api dev PORT` | stdout: `8080\n`, exit 0 |
| `envii get api dev TOKEN` | stdout: `s3cr3t\n`, exit 0 (raw, unmasked) |
| `envii get web dev PORT` | error `project "web" not found`, exit != 0 |
| `envii get api prod PORT` | error `env "prod" not found in project "api"`, exit != 0 |
| `envii get api dev NOPE` | error `key "NOPE" not found in project "api" env "dev"`, exit != 0 |
| wrong arg count | cobra arg error, exit != 0 |

Add to `internal/cli/commands.go` after `exportCmd`:

```go
// getCmd: envii get <project> <env> <KEY>
func getCmd() *cobra.Command {
	cmd := &cobra.Command{
		Use:   "get <project> <env> <KEY>",
		Short: "Print a single variable's value (for use in shell scripts)",
		Example: `  envii get my-api dev DB_URL
  export DB_URL=$(envii get my-api dev DB_URL)`,
		Args: cobra.ExactArgs(3),
		RunE: func(_ *cobra.Command, args []string) error {
			v, _, _, err := loadVault()
			if err != nil {
				return err
			}
			env, err := resolveEnv(v, args[0], args[1])
			if err != nil {
				return err
			}
			variable := env.FindVar(args[2])
			if variable == nil {
				return fmt.Errorf("key %q not found in project %q env %q", args[2], args[0], args[1])
			}
			fmt.Fprintln(defaultIO.Stdout(), variable.Value)
			return nil
		},
	}
	return cmd
}
```

In `internal/cli/cli.go`, register it:

